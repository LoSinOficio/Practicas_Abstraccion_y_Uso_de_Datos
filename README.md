## Uso
1. Abre el archivo que desees revisar.
2. Compila el programa con un compilador de C++.
3. Ejecuta el archivo para probar su funcionamiento.

Ejemplo:

```bash
g++ "Practica 01.cpp" -o practica1
./practica1
```
